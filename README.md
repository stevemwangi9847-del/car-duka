# 🚗 Car Duka

A modern car-selling web application where buyers can browse, filter, and book viewings for cars — and admins can manage listings and bookings. Includes an AI chatbot and WhatsApp integration.

## ✨ Features

- 🔍 Advanced car search (make, model, price, fuel type, transmission, year)
- 📅 Book a viewing for any car (login required)
- 🛠️ Admin dashboard to add/edit/delete cars and manage bookings
- 📤 Upload car images from local files
- 🤖 Built-in AI chatbot for customer questions
- 📱 WhatsApp contact integration (0718870024)
- 🔐 Secure authentication (hashed passwords, session-based)
- 👥 Role-based access (admin vs buyer)

## 🛠️ Tech Stack

- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript
- **Auth:** Werkzeug password hashing + Flask sessions
